# Queue_Manager
## Как запускать?
1) Создать .env в корневой директории, настроить переменные, указать нужный USE_VPN
   ```
   0 для использования локальной модели
   1 для скачивания с серверов HuggingFace
   ```
2) Сделать docker image:
   ```cmd
   docker build -t queue --no-cache .
   ```
3) Запустить контейнер
   ```cmd
   docker-compose up
   ```

## Как открыть отладку?
1) Для FastAPI перейти по адресу: http://localhost:8000/docs#
2) Для RabbitMQ: http://localhost:33
